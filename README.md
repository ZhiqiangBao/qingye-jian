不是冷冰冰的文档页，而是摊开在书桌上的一页纸。  
适合写学习计划、考研日程、日常手账草稿——好看，也能认真写。

## 能做什么

- 手账风预览：横线纸、多套皮肤、笔迹字体  
- 贴纸备注：形状、文字、拖动，按页保存  
- 任务勾选与完成进度  
- 大标题可强制顶到新页页首  
- 导入计划模板，导出打印 / PDF

## 小技巧

想让某一段从新一页最上方开始，在标题上一行写：

```md
<!-- pagebreak -->
## 大标题
```

更多写法见仓库内 [`help/编辑技巧.md`](help/编辑技巧.md)，或启动后点「帮助」。
