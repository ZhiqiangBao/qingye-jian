# 青叶笺 · GitHub Pages Demo

本目录由 `python packaging/sync_pages_demo.py` 生成。
在仓库 Settings → Pages 中选择 Deploy from branch，文件夹选 `/docs`。

**说明：** 在线 Demo **不提供 PDF 导出**（无本地服务 / 无头浏览器）。试用排版与贴纸请用 Demo；需要 PDF 请下载桌面版。

皮肤 JSON 可设 `orientation: "landscape"` 或 `aspect: "16 / 9"` 自定义预览比例，详见仓库根目录 `skins/README.txt`。
