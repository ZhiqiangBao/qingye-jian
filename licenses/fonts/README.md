# 字体许可文件（Google Fonts / SIL OFL）

本目录存放青叶笺通过 Google Fonts 使用的字体之 **OFL（SIL Open Font License）** 原文，来源为 [google/fonts](https://github.com/google/fonts) 仓库。

| 目录 | 字体名 | 许可 |
|------|--------|------|
| `Gaegu` | Gaegu | OFL |
| `LiuJianMaoCao` | Liu Jian Mao Cao（刘建毛草） | OFL |
| `LongCang` | Long Cang（龙藏） | OFL |
| `MaShanZheng` | Ma Shan Zheng（马善政） | OFL |
| `NotoSansSC` | Noto Sans SC | OFL |
| `ZCOOLXiaoWei` | ZCOOL XiaoWei（站酷小薇） | OFL |
| `ZhiMangXing` | Zhi Mang Xing（志莽行书） | OFL |

每个子目录内的 `OFL.txt` 为对应字体的完整许可文本。
