# 青叶笺 · 编辑技巧

本地手账风格 Markdown 编辑器。下面是常用写法与界面操作，可随时点顶部「帮助」再看。

---

## 快速上手

1. 双击 **青叶笺.exe** 启动（无黑色终端；浏览器会自动打开）
2. 默认打开 `document/` 内容库（与程序源码分开）
3. 左侧点选 `.md`，中间改草稿，右侧看成品页
4. `Ctrl + S`（Mac：`⌘ + S`）或点「贴好保存」
5. 用完点顶部「退出」，关闭本地后台服务

视图切换：

| 按钮 | 作用 |
|------|------|
| 摊开 | 左编辑 + 右预览 |
| 草稿 | 只看编辑区 |
| 阅读 | 只看成品页 |

---

## 工作区与文件

- **工作区**：限制可读/可写的 Markdown 根目录；默认是程序下的 `document/`
- **刷新目录**：重新扫描当前文件夹
- **重载本页**：放弃未保存改动，从磁盘重新读入
- 可进入子文件夹；只显示 `.md`

## Markdown 常用写法

```md
# 一级标题
## 二级标题
### 三级标题

> 引用 / 今日备注

- 普通列表
1. 有序列表

**加粗** · *斜体* · `行内代码`

| 时间 | 内容 |
|------|------|
| 09:00 | 精读 |
```

分割线用单独一行的 `---`。

## 任务勾选与进度

写成任务列表（草稿纸里改 `[ ]` / `[x]`），顶部进度条会跟着变：

```md
- [ ] 还没做
- [x] 已完成
```

成品页上的小方框**只作展示**，不能点。若要在纸面上留下完成记号，用上方贴纸栏的 **「✓ 贴勾」**（和贴纸一样可贴、可拖、可翘边撕掉）。记得保存草稿纸里的 Markdown。

## 强制分页（标题顶到页首）

想让某个大标题从**新一页最上方**开始，在标题正上方加一行注释：

```md
<!-- pagebreak -->
## 上午时段
```

也认：

- `<!-- page-break -->`
- `<!-- page-top -->`
- `<!-- journal: pagebreak -->`

说明：

- 标识符本身**不会显示**在成品页
- 预览翻页与「导出打印」都会在此处分页
- 编辑区（草稿纸）仍是连续滚动，不分页

---

## 成品页与翻页

- 预览**长宽比**由皮肤 `paper` 决定（界面写作「A4比例 / A5横 / 自定义比」等）
- `paper.orientation`: `portrait`（默认）或 `landscape`（横页，对调 a4/a5/b6 比例）
- `paper.aspect`: 如 `"16 / 9"`，自定义比，**优先于** size + orientation
- **注意：** a4 / a5 / b6 **不是**打印机里的物理纸型，只影响屏幕成品页比例
- 皮肤纸面尺寸会传给分页引擎：按纸面高度切页，长文/长表会拆到下一页，尽量不让文字撑出成品页
- 导出 PDF 按当前屏幕成品页画布尺寸（像素→mm），随窗口与布局变化
- 内容超出一页时，预览底部用「上一页 / 下一页」翻页
- 不在编辑区时，可用键盘 **← / →** 翻页
- 翻页只影响显示与导出，不改 md 正文结构（除非你写了分页注释）

## 贴纸

1. 点「贴纸」打开工具条
2. 「＋ 贴一张」选形状、写字、调倾斜与大小
3. 贴纸贴在**当前成品页**，翻页后各页独立
4. 拖动调整位置；点贴纸**翘边**可撕掉
5. 「清空本页」只清当前成品页的用户贴纸

可开关：

- **显示贴纸**：用户贴纸
- **皮肤小装饰**：皮肤自带的小 emoji（写在皮肤 JSON 里）

贴纸保存在浏览器本地，按文件路径记忆；换浏览器或清站点数据会丢失。

## 字体

点「字体」可选手写 / 印刷风格，例如：

- 青叶手写、毛笔行书、潦草速记
- 龙藏笔锋、小薇标题、工整印刷

选择会记住在本机浏览器里。

---

## 皮肤

- **换皮肤**：切换配色、预览比例、横线、边线、氛围
- **导入皮肤**：粘贴或选择 JSON，写入 `skins/`
- 说明见程序目录 `skins/README.txt`

`paper.size`（a4 / a5 / b6 / square / full / wide）只定**预览比例**；`full` / `wide` 为铺满工作区。  
可另写 `orientation` / `aspect`（见上）；旧皮肤不写则仍为竖页。界面后缀为「A5比例 / A5横 / 自定义比」。

---

## 模板

1. 点「导入模板」
2. 选 `templates/` 里的模板 →「导入并打开」
3. 会复制到当前浏览文件夹，不改坏模板原件

自建模板：把 `.md` 放进 `templates/`，可选在文件头加：

```md
<!-- journal-template
title: 显示名称
desc: 一两句介绍
-->
```

---

## 导出打印

1. 点「导出打印」
2. 桌面版选「下载 PDF」（矢量推荐；需本机 Edge/Chrome）或位图备选
3. 「打开导出页」可下载 HTML，或用系统打印（纸型常被系统改写，尺寸不一定等于成品页）

PDF 页面尺寸 = 当前屏幕成品页画布，**不是**皮肤名里的 A4/A5 打印纸。  
在线 Demo 不提供 PDF。

---

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl/⌘ + S` | 保存 |
| `←` / `→` | 成品页翻页（焦点不在输入框时） |

```text
qingye-jian/
  help/           ← 本帮助文档
  templates/      ← 计划模板
  skins/          ← 手账皮肤
  document/       ← 默认工作区（你的内容）
```

更多皮肤字段见 `skins/README.txt`；模板说明见 `templates/README.txt`。
